# SecurStack Homebrew Tap

Official Homebrew tap for the standalone [SecurStack CLI](https://github.com/securstack/securstack-cli).

## Install

```sh
brew tap securstack/tap
brew install securstack
```

The formula downloads the immutable binary for the current platform from [downloads.securstack.io](https://downloads.securstack.io/) and verifies its SHA-256 checksum.

## Upgrade

```sh
brew update
brew upgrade securstack
```
